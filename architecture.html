Request Data Flow

1
User changes a filter
User selects Time Period, Warehouse, Category, or Status in FilterBar.vue. The useFilters composable (singleton) updates the corresponding ref.
2
View detects change via watcher
Each view has a watch() on the filters composable. When any filter changes, the view's loadData() method is called automatically.
3
api.js builds query params and fires Axios request
getCurrentFilters() returns { warehouse, category, status, month }. Axios appends non-'all' values as query params, e.g. GET /api/orders?warehouse=Tokyo&status=Delivered&month=2025-03
4
FastAPI filters in-memory data and validates response
apply_filters() chains warehouse, category, status list-comprehensions. filter_by_month() supports YYYY-MM and quarter formats (e.g. Q1-2025). Pydantic models validate output shape before returning.
5
Vue updates reactive state and re-renders
Response is stored in a ref (e.g. allOrders). Derived computed() properties (top products, category totals, chart data) recalculate automatically, triggering the template to re-render.

API Endpoints

Inventory
GET/api/inventoryAll stock items — filters: warehouse, category
GET/api/inventory/{item_id}Single item by ID
Orders
GET/api/ordersAll orders — filters: warehouse, category, status, month
GET/api/orders/{order_id}Single order with line items
Dashboard
GET/api/dashboard/summaryKPI aggregates — filters: all 4; returns inventory value, low stock count, pending/backlog counts, order value
Demand & Backlog
GET/api/demandDemand forecasts with trend classification (Increasing / Stable / Decreasing)
GET/api/backlogShortage items; each includes has_purchase_order flag derived from in-memory PO store
Spending
GET/api/spending/summaryTotal revenue, costs, profit, avg order value
GET/api/spending/monthlyMonth-by-month revenue vs costs breakdown
GET/api/spending/categoriesSpend by product category
GET/api/spending/transactionsRecent transaction ledger
Reports
GET/api/reports/quarterlyPer-quarter: total orders, revenue, avg order value, fulfillment rate
GET/api/reports/monthly-trendsPer-month: order count, revenue, delivered count
Tasks
GET/api/tasksUser task list (in-memory)
POST/api/tasksCreate a new task
PATCH/api/tasks/{taskId}Toggle task complete/incomplete
DELETE/api/tasks/{taskId}Delete a task
Purchase Orders
POST/api/purchase-ordersCreate PO from backlog item (supplier, qty, unit cost, expected delivery)
GET/api/purchase-orders/{backlogItemId}Retrieve PO by the backlog item it resolves
